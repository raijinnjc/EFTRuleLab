## Confirmed defects corrected

- Selected FY2021 Policy amount could expose global FY2022 rule provenance. The inspector now uses the inspected rule, while global selection changes only on the same original actions.
- Source controls imposed454px intrinsic width at320px/200% text. Explicit shrinkable grid tracks/labels fix actual overflow.
- Fresh review found a raw exact amount in Funds figcaption escaping the analytical panel despite no document overflow. Caption emergency wrapping and a text-range containment regression address it.
- S1/S2 action containers followed by disclosures did not match the inherited last-child flex selector. Explicit action layout separates inspection and external-record actions.

All three question labels and precise source/action descriptions may wrap rather than truncate. Large figure controls are intentional full targets, not marketing buttons. Tables and records scroll locally; no content or research qualification is removed to satisfy layout metrics.

## Accessibility scope and exceptions

Actual axe-core4.14.0 WCAG2A/AA,2.1AA and2.2AA tagged scans cover12routes plus source dialog at1440/390 (26states). Two automated target-size flags remain on narrow proportional7%segments. Both have equivalent full-size native selectors on the same page (and Puzzle has a full-size performance-pool action); the Equivalent exception under WCAG2.5.8 is documented and regression-tested. No rule is disabled and proportions are not inflated. See [raw results](ACCESSIBILITY.json).

The manual ARIA follow-up gave three existing labeled figures explicit group roles, covered by a new regression. Remaining incomplete color-contrast checks are retained for human inspection; these are not counted as passes. Visible state text, focus rings, exact labels and full-size alternatives remain; tests cover keyboard/dialog/history/reduced-motion behavior and all five widths at200% text. No screen-reader certification, Safari/device coverage or real first-reader success is claimed.

Rendered Hallmark summary and dispositions are added in the release report after the final sweep. Its raw flags are not represented as a clean pass or allowed to override source integrity, truthful chart proportions or required academic qualifications.
