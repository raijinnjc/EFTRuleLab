# Proposed visitor journey and preservation contract

Status: proposal for Checkpoint A. **Not implemented.** No new theme, research feature or replacement PRD.

## Main journey

The logo opens the existing introduction. Keep the mandatory headline and atmospheric photo. Then present three compact question-led destinations:

| Compact navigation label | Full scene question | Existing public hash | Primary job |
|---|---|---|---|
|01 What we can prove|What can we prove?|#puzzle|Inspect the calculated fiscal pool versus the published ledger; Test 1 PASS/Rp0.|
|02 What's missing|What can't we reproduce?|#evidence-gap|Inspect missing decision evidence; independent Test 2 INCOMPLETE.|
|03 Proposed verification|How could verification improve?|#protocol|Understand ARP's approved-input, withheld-target and comparison contract; proposal only.|

Navigation order is a reading order, not logical implication. Test 2 neither follows from nor becomes valid because Test 1 passes. Give each a distinct question, required evidence and result.

Use one shared chapter-navigation presentation rather than different repeated header/tab descriptions. Desktop: compact navigation / dominant graphical canvas / selected context. Mobile: compact question navigation, canvas, then contextual disclosure/detail. One primary chapter is visible at a time; do not stack all analytical tools below it. Do not turn these three chapters into a locked funnel—deep links and direct tool entry remain available.

## Journey examples

**First-time judge:** introduction → 01 pool/ledger comparison → 02 missing decision inputs → 03 proposed independent review. Source actions are visible throughout; no requirement to operate Policy Studio or filters first.

**Researcher:** any original tool deep link → exact selected data/source → related tool or return to invoking chapter. Returning from a tool restores the original chapter and existing analytical state.

**Reviewer of a known award:** #awards → search/select village and exact provenance → 02 decision-evidence boundary → 03 proposed evidence requirements. No inferred score/rank appears.
